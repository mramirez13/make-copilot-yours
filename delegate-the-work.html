Start with the help you need, not the size of the prompt. Explore and refine in Chat. Delegate a defined, multi-step outcome in Cowork.

Copilot Chat · think with me

Use it when
You want an explanation, ideas, a summary, a draft, or help deciding what to do next. You expect to steer the conversation as the answer takes shape.
Write the request as
Context + Goal + Source + Expectations. Name the immediate help you want and what a useful response looks like.
Expect to get
An answer, analysis, draft, or table you can refine with follow-ups. File and app features depend on your experience; Chat is not limited to plain text.
Help me prepare for an upcoming project review. Using the notes I provide, summarize progress, surface open decisions, and suggest five questions to ask. Return a concise briefing in this chat; flag gaps rather than inventing details.

Copilot Cowork · carry this through

Use it when
The outcome is clear and you want several steps carried out across available files and Microsoft 365 tools—not just advice about how to do them.
Write the request as
Outcome + Sources + Deliverables + Working agreement. Add formats, destination, scope, and where you want approval or review.
Expect to get
A visible work sequence, completed deliverables such as documents or spreadsheets, and a report of what was done or blocked. Available tools, permissions, and your approvals determine what can actually happen.
Prepare my project review package using only the notes I provide. Create a one-page Word briefing and an Excel action tracker. Show your plan first and wait for approval. Then create new draft files in the folder I confirm, and return their links with unresolved items. Do not send or share anything.

The difference is the working agreement—not a magic phrase. Chat can help with complex work too, and Cowork can answer questions. Use Chat when you want to steer the thinking; use Cowork when you can define the work to carry through. Cowork access and usage limits depend on your organization and account. You can compare both request styles here even if only Chat is available.
