Build beside this page · about 4 minutes
Give your guide a home in Copilot
Keep this page open for the text and the test prompts. You build and test in Microsoft 365 Copilot—not here.

      

        
1
Agents → New agent → Describe
In Microsoft 365 Copilot's navigation, under Agents, select New agent. On Describe, paste your build description and send it. Follow the builder's prompts. Natural language is the recommended starting point.
If Describe is not offered in your language, choose Skip to configure and use the optional individual fields above.

        
2
Configure → Knowledge → Upload
Open Configure. Review Name, Description, and Instructions. Under Knowledge, choose the upload control to upload Workshop-Practice-Guidelines.txt from your device.
Verify it appears under Uploaded files. Wait until the upload is complete and the file is no longer gray. If a source shows Preparing, wait for it to be ready before testing source answers. This can take a few minutes.
Naming the file in a description does not upload it, connect it, or grant access. If the upload fails, retry with this downloaded .txt or ask your facilitator; do not use a real handbook instead.

        
3
Keep the practice focused
In Configure, turn off Search all websites and Reference people in organization where available. Remove any unrelated sources the builder added; leave broad work sources such as email and Teams off. If available, turn on Only use specified sources.
These settings prioritize the supplied source; they do not block all general AI knowledge. Instructions are behavioral guidance, not guaranteed technical enforcement. You still need to review the answers.

      

    


    

      
Try it · about 3 minutes
Ask something it can answer. Then something it can't.
Open Try it in Agent Builder. It is enabled once Name, Description, and Instructions are present; that alone does not mean your knowledge file is ready. Paste these prompts there, one at a time.

      

        
Find the answer
Explain the first week
According to the workshop handbook, what should an employee and manager do during the first week? Identify the source section.
Look for: day-one priorities and a buddy; days 2–3 orientation and questions; day-five review. Source: section 1.

        
Change the format
Make it practical
Turn section 2 of the workshop handbook into a short learning-participation checklist. Keep the timing and responsibilities exactly as written.
Look for: agree one session, record one takeaway within two working days, discuss one application at the next check-in. No invented deadlines.

        
Notice the unknown
Don't invent authority
Who has authority to approve an exception to the learning-participation rules, and what is the approval deadline?
Look for: neither is specified. Section 4 directs questions to the handbook owner, but does not grant that person exception authority.

      

      
If an answer drifts: confirm the file is ready in Knowledge, compare the answer with the handbook, then refine Instructions in Configure and try again. Ask it to name the file and section where possible; automatic citations are not guaranteed. This page does not run or assess your agent.

    


    

      
Create for your own use · about 1 minute
A learning prototype, not another policy owner

        
When you're satisfied with the tests, select Create in Agent Builder. Keep it for your own use. Do not choose sharing, distribution, or organization-publishing options during this exercise.

        
For real work, reuse before rebuilding. Check for an approved workplace agent and involve the content owner before making a workplace version. Use one maintained, approved SharePoint source—not personal policy uploads from every participant. The content owner maintains that source; the agent helps people find and understand it.

        
The fictional upload is only a learning aid. A workplace version needs the appropriate permissions, ownership, and organizational review. No workplace deployment is part of today's practice.
