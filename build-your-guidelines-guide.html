Guidelines Guide

Give people a simpler way to find and understand guidance. You'll turn a short handbook into an agent that answers questions, explains the steps, and points back to its source.

Start with the handbook →Go to your agent brief

What makes this an agent?

A regular prompt gives Copilot a task for a conversation. An agent brings a reusable purpose, instructions, and knowledge together, so people can return to the same focused helper.

Your Guidelines Guide will explain first-week steps, turn learning guidance into a checklist, and say when the handbook doesn't answer a question. Build it in Agent Builder inside Microsoft 365 Copilot—no code or Copilot Studio project needed.

Download → Describe → Add knowledge → Try it → Create

Keep this page beside Microsoft 365 Copilot on desktop web. If New agent or knowledge upload is unavailable for your account, pair with someone who has access or ask your facilitator.

1 · Meet your source

Start with the guidance your agent will use

The download is a short employee and manager handbook with four sections: first-week planning, learning participation, manager communication, and questions the source doesn't answer. Your agent will help people use that guidance—not write new rules.

Plan the first week

“On day one, the employee and manager agree three first-week priorities and identify a buddy for everyday questions.”

Ask the agent to explain the first week as a simple plan.

Make learning actionable

“Within two working days after attending the session, the employee records one useful takeaway in a personal learning note.”

Ask it to turn the learning steps into a checklist.

Recognize a missing answer

“This handbook does not specify who may approve exceptions or a deadline for approving them.”

A useful agent should identify that gap, not invent an approval process.

Download your handbook

Save Workshop-Practice-Guidelines.txt to your device. In step 3, you'll upload this file as your agent's knowledge. Everyone starts with the same source; you customize how the guide helps.

3 · Build and add knowledge
Connect the instructions to the handbook
The description shapes how your guide behaves. The uploaded file gives it the material to answer from. You need both.

      

        
A
Review what Agent Builder created
After pasting the description into Describe, follow the builder's prompts. Open Configure and review the generated Name, Description, and Instructions.
If Describe is not offered in your language, choose Skip to configure and use the optional individual fields above.

        
B
Knowledge → Upload your handbook
Under Knowledge, upload Workshop-Practice-Guidelines.txt from your device. If you haven't saved it yet, return to the download.
Verify it appears under Uploaded files. Wait until the upload is complete and the file is no longer gray. If it shows Preparing, wait for it to be ready before asking source questions.
Naming the file in the description doesn't attach it. If upload fails, retry or ask your facilitator.

        
C
Keep the knowledge focused
Turn off Search all websites and Reference people in organization where available. Remove unrelated sources; leave broad work sources such as email and Teams off. If available, turn on Only use specified sources.
Source settings and instructions guide its answers, but aren't a guarantee against unsupported information. Compare answers with the handbook as you try it.

      

    


    

      
4 · Try your agent
Ask it to explain, reformat, and recognize a gap
Once the handbook is ready, open Try it in Agent Builder. Paste these prompts one at a time to see how the same agent uses its instructions and knowledge.

      

        
Find the answer
Explain the first week
According to the workshop handbook, what should an employee and manager do during the first week? Identify the source section.
Look for: day-one priorities and a buddy; days 2–3 orientation and questions; day-five review. Source: section 1.

        
Change the format
Make it practical
Turn section 2 of the workshop handbook into a short learning-participation checklist. Keep the timing and responsibilities exactly as written.
Look for: agree one session, record one takeaway within two working days, discuss one application at the next check-in. No invented deadlines.

        
Notice the unknown
Don't invent authority
Who has authority to approve an exception to the learning-participation rules, and what is the approval deadline?
Look for: neither is specified. Section 4 directs questions to the handbook owner, but does not grant that person exception authority.

      

      
If an answer drifts: confirm the file is ready in Knowledge, compare the answer with the handbook, then refine Instructions in Configure and try again. Ask it to name the file and section where possible; automatic citations are not guaranteed. This page does not run or assess your agent.

    


    

      
5 · Create your guide
A focused helper you can return to

        
When you're satisfied with the answers, select Create in Agent Builder and keep the guide for your own use during the workshop.

        
For real work, reuse before rebuilding. Check for an approved workplace agent and involve the content owner before making a workplace version. Use one maintained, approved SharePoint source—not personal policy uploads from every participant. The content owner maintains that source; the agent helps people find and understand it.
