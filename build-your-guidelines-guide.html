What makes this an agent?

An agent is a helper you set up once and return to. You give it a job, instructions, and a handbook to answer from.

This guide will explain first-week steps, make learning checklists, and say when the handbook doesn't have an answer. You'll build it in Agent Builder inside Microsoft 365 Copilot. No coding needed.

Step 1 of 5 · Download

Get the handbook

Your guide will answer from this short employee and manager handbook. Skim the examples, then download the file. It covers the first week, learning, manager check-ins, and unanswered questions.

Plan the first week

“On day one, the employee and manager agree three first-week priorities and identify a buddy for everyday questions.”

Ask the agent to explain the first week as a simple plan.

Make a learning checklist

“Within two working days after attending the session, the employee records one useful takeaway in a personal learning note.”

Ask it to turn the learning steps into a checklist.

Recognize a missing answer

“This handbook does not specify who may approve exceptions or a deadline for approving them.”

A useful agent should identify that gap, not invent an approval process.

Step 3 of 5 · Upload
Add the handbook in Copilot
In Agent Builder, open Configure. The description tells your guide how to help; the file gives it the answers.

      

        
A
Review your guide's details
Check the Name, Description, and Instructions Copilot filled in.
If Describe isn't available, choose Skip to configure and use the individual fields in step 2.

        
B
Knowledge → Upload your handbook
Under Knowledge, upload Workshop-Practice-Guidelines.txt from your device. If you haven't saved it yet, return to the download.
Verify it appears under Uploaded files. Wait until the upload is complete and the file is no longer gray. If it shows Preparing, wait for it to be ready before asking source questions.
Naming the file in the description doesn't attach it. If upload fails, retry or ask your facilitator.

        
C
Use just the handbook
Turn off Search all websites and Reference people in organization if shown. Leave email, Teams, and other sources off. If available, turn on Only use specified sources.
These settings help it stay focused; it can still make mistakes.

      

      
When the handbook is uploaded and ready, try asking your guide a question.

Step 4 of 5 · Try
Ask your guide a question
Open Try it in Agent Builder. Copy a prompt below, paste it there, and read the answer. Try the others to see what your guide can do.

      

        
Find the answer
Explain the first week
According to the workshop handbook, what should an employee and manager do during the first week? Identify the source section.
Look for: day-one priorities and a buddy; days 2–3 orientation and questions; day-five review. Source: section 1.

        
Change the format
Make it practical
Turn section 2 of the workshop handbook into a short learning-participation checklist. Keep the timing and responsibilities exactly as written.
Look for: agree one session, record one takeaway within two working days, discuss one application at the next check-in. No invented deadlines.

        
Notice the unknown
Don't invent authority
Who has authority to approve an exception to the learning-participation rules, and what is the approval deadline?
Look for: neither is specified. Section 4 directs questions to the handbook owner, but does not grant that person exception authority.

      

      
Copy a prompt, then paste it in Try it.

      
Answer doesn't match? Check the file is ready under Knowledge. Use the handbook to spot what's wrong, update Instructions in Configure, and try again.
